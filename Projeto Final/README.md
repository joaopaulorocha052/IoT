# Projeto Final
Projeto da disciplina de Internet das Coisas (IoT) do curso de Engenharia de Computação da Universidade Federal de São Paulo (UNIFESP). Seus resultados serão considerados para o cômputo final da disciplina.

## Ideia Principal
Desenvolver um sistema de Controle de Cruzeiro Adaptativo, capaz de manter uma distância segura de objetos em sua frente. A telemetria de dados do carrinho mantém os dados de distância a frente, inclinação e velocidade do carrinho, sendo exibidos em um cliente externo. Além disso, a distância será definida também por meio da interface pelo usuário.
